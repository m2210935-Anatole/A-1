# 3D Printer Booking

Веб-приложение для бронирования времени работы на 3D-принтерах.

Система построена по клиент-серверной архитектуре. Клиентская часть работает в браузере, обмен данными с сервером происходит через **WebSocket**, а данные хранятся в **SQLite**.

## Возможности

### 👤 User

Обычный пользователь может:

- авторизоваться в системе;
- просматривать список 3D-принтеров;
- просматривать расписание;
- создавать бронирование;
- указывать время начала и окончания;
- добавлять комментарий к бронированию;
- отменять только свои бронирования;
- не может изменять чужие бронирования;
- не может добавлять или удалять 3D-принтеры;
- не может управлять другими пользователями.

### 👑 Admin

Администратор имеет расширенные права:

- добавлять пользователей;
- удалять пользователей;
- назначать пользователю роль `Admin` или `User`;
- просматривать список всех пользователей;
- добавлять 3D-принтеры;
- удалять 3D-принтеры;
- создавать бронирования для любых пользователей;
- изменять любые бронирования;
- удалять любые бронирования;
- управлять расписанием.

Сервер проверяет права доступа для каждой административной операции.

# Установка

## 1. Клонирование репозитория

```bash
git clone https://github.com/USERNAME/3d-printer-booking.git
```

Перейдите в папку проекта:

```bash
cd 3d-printer-booking
```

---

## 2. Установка зависимостей

```bash
npm install
```

Если зависимости ещё не были установлены:

```bash
npm install ws better-sqlite3
```

---

## 3. Запуск сервера

```bash
node server.js
```

или:

```bash
npm start
```

После запуска в консоли появится:

```text
======================================
3D PRINTER BOOKING SERVER
======================================
HTTP:      http://localhost:3000
WebSocket: ws://localhost:3000
======================================
Default Admin: admin / 1234
Default User:  user / 1234
======================================
```

---

## 4. Открытие приложения

Откройте в браузере:

```text
http://localhost:3000
```

# База данных

Используется SQLite.

База содержит три основные таблицы.

## users

Хранит пользователей системы.

```text
id
login
password
role
created_at
```

Роли:

```text
Admin
User
```

---

## printers

Хранит 3D-принтеры.

```text
id
name
description
active
created_at
```

---

## bookings

Хранит бронирования.

```text
id
printer_id
user_id
start_time
end_time
comment
created_at
```

Связи:

```text
users
   │
   │ user_id
   ▼
bookings
   ▲
   │ printer_id
   │
printers
```

# Бронирование

При создании бронирования сервер проверяет:

1. Авторизован ли пользователь.
2. Существует ли выбранный принтер.
3. Корректно ли указано время.
4. Не существует ли пересекающееся бронирование.
5. Для какого пользователя создаётся бронь.

Для обычного пользователя бронирование автоматически создаётся от его имени.

[https://github.com/m2210935-Anatole/A-1/issues/5](https://github.com/user-attachments/assets/98fa3209-db68-4846-8226-e9c4c2b2851f)

Admin может выбрать другого пользователя.

# Проверка пересечения

Сервер не позволяет создать две брони на один принтер в одно время.

[https://github.com/m2210935-Anatole/A-1/issues/1#issue-5564883242](https://github.com/user-attachments/assets/93dba97a-9ea4-41da-8922-6c3c75a93b4d)

Используется проверка:

```sql
WHERE printer_id = ?

AND start_time < ?

AND end_time > ?
```

Например:

```text
10:00 ───────── 12:00
```

и

```text
11:00 ───────── 13:00
```

будут конфликтовать.

А:

```text
10:00 ───────── 12:00

12:00 ───────── 14:00
```

могут существовать одновременно.

# WebSocket API

Клиент и сервер обмениваются JSON-сообщениями через WebSocket.

## Авторизация

Клиент:

```json
{
    "type": "login",
    "login": "admin",
    "password": "1234"
}
```

Сервер:

```json
{
    "type": "loginResult",
    "success": true,
    "user": {
        "id": 1,
        "login": "admin",
        "role": "Admin"
    }
}
```

---

## Создание пользователя

Только Admin:

```json
{
    "type": "createUser",
    "login": "newuser",
    "password": "12345",
    "role": "User"
}
```

---

## Удаление пользователя

Только Admin:

```json
{
    "type": "deleteUser",
    "userId": 4
}
```

---

## Добавление принтера

Только Admin:

```json
{
    "type": "addPrinter",
    "name": "Bambu Lab X1C",
    "description": "FDM 3D-принтер"
}
```

---

## Удаление принтера

Только Admin:

```json
{
    "type": "deletePrinter",
    "printerId": 2
}
```

---

## Создание бронирования

```json
{
    "type": "createBooking",
    "printerId": 1,
    "startTime": "2026-09-18T10:00",
    "endTime": "2026-09-18T12:00",
    "comment": "Печать корпуса"
}
```

---

## Удаление бронирования

Admin может удалить любое бронирование.

User может удалить только своё.

```json
{
    "type": "deleteBooking",
    "bookingId": 10
}
```

---

## Изменение бронирования

Только Admin:

```json
{
    "type": "updateBooking",
    "bookingId": 10,
    "printerId": 2,
    "userId": 3,
    "startTime": "2026-09-18T14:00",
    "endTime": "2026-09-18T16:00",
    "comment": "Изменённое бронирование"
}
```
